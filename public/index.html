ℹ️ System Architecture & RAG Details

This application is powered by an enterprise-grade Hybrid RAG System:

  • PyMuPDF & Tesseract OCR Inspection: Analyzes font tables, image resolutions, object counts, text density, and falls back to OCR for scanned pages.
  • Deterministic Rule Engine: Fast-path matching for clear cases (Scanned PDFs, text-heavy PDFs).
  • FAISS Vector RAG Engine: Vector semantic search against a knowledge base of compression strategies for ambiguous documents.
  • LLM Synthesizer & RAG Assistant: Page-level windowed chunking, FAISS vector indexing, and synthesized answer generation.
  • Visual Quality Engine: Computes PSNR (dB) and SSIM (%) quality retention scores.
  • Safe Rebuild Pipeline: PyMuPDF stream deflating paired with Ghostscript binary downsampling.
